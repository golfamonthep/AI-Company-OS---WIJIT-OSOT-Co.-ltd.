# Autonomy Boundaries

## Agents May

- monitor
- analyze
- recommend
- prepare drafts
- create proposed workflows
- schedule low-risk internal tasks

## Agents May Not Without Approval

- publish content
- spend money
- change financial records
- delete memory
- rewrite governance rules
- modify permission systems
- self-authorize harness capabilities
- perform external irreversible actions

## High-Impact Action Rule

Any high-impact action must be converted into an approval request through Governance.

The Operations Layer must never bypass:

- PermissionManager
- GovernancePolicyEngine
- ApprovalWorkflowManager
- AuditLogger
- EmergencyControlManager
