# Ads Performance Review Workflow

## Purpose

Review a generated campaign for paid-performance potential before governance approval or live ad activation.

## Scope

MVP scope is Content Department collaboration only. This workflow reviews the Mother-and-baby TikTok Campaign package generated by the Content Production Workflow.

## Inputs

- Marketing audience analysis
- Content Creator hooks, captions, and scripts
- Campaign goal
- Product summary
- Reviewer feedback when available

## Steps

1. Receive campaign package from Content Production Workflow.
2. Run CTR Analysis.
3. Run Audience Analysis.
4. Run Campaign Performance Review.
5. Run Creative Performance Review.
6. Run Ad Optimization Suggestions.
7. Run Budget Efficiency Analysis.
8. Save Ads Performance memory.
9. Log learning event.
10. Route campaign package to governance approval.

## Outputs

- CTR prediction
- Audience targeting suggestions
- Creative performance feedback
- Optimization recommendations
- Budget-efficiency guardrail
- Reporting summary
- Learning signals
- Governance notes

## Governance

- No external ad action is executed.
- No spend is approved by this workflow.
- Budget changes, live launch, external platform writes, and claims-sensitive targeting require human/CFO approval.

## Memory Usage

- Retrieve successful campaign patterns when available.
- Save campaign performance insights.
- Save optimization learnings.
- Share creative recommendations with Content Creator AI through workflow output.

## Success Metrics

- CTR prediction produced.
- Recommendations are specific and actionable.
- Budget guardrail is present.
- Learning event is logged.
- Dashboard displays review output.
- Governance approval remains required before external action.
