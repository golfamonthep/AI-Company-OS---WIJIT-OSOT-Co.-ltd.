# Video Editor Skills

## Skill: Short Video Production Plan

### SOP

1. Read script and campaign objective.
2. Break script into scenes.
3. Define shot list and asset requirements.
4. Define editing rhythm, captions, and transitions.
5. Define export/platform notes.

### Inputs

- Script
- Channel/platform
- Product visuals
- Brand style
- Campaign objective

### Outputs

- Shot list
- Editing instructions
- Asset checklist
- Caption/subtitle notes
- Platform export notes

### Guardrails

- Do not claim video has been edited unless video harness ran.
- Do not request unavailable assets as if they exist.
- Escalate missing visual assets to Marketing/Admin.

## Skill: Video Creative Review

### Workflow

- Check opening hook
- Check visual clarity
- Check pacing
- Check CTA
- Check platform fit
- Provide revision notes
