# Business Tool Connectors

## Notion

- connector_id: notion
- read_actions: read selected pages
- write_actions: create page draft
- approval_required: create page draft

## Slack

- connector_id: slack
- read_actions: read selected channels
- write_actions: send message
- approval_required: send message

## Shopify

- connector_id: shopify
- read_actions: read orders, read products
- write_actions: create product draft, publish product
- approval_required: publish product

## Stripe

- connector_id: stripe
- read_actions: read metrics
- write_actions: modify financial data
- approval_required: all write actions

## LINE OA

- connector_id: line-oa
- read_actions: read insights
- write_actions: send broadcast
- approval_required: send broadcast
