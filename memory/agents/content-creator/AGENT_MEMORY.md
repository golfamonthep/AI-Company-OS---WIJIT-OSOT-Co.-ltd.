# Content Creator Agent Memory

## Working Style

- Prefer concrete hooks over broad motivational copy.
- Use audience pain, checklist, story, and CTA patterns.
- For TikTok, make the first 3 seconds specific and visual.

## Mother And Baby Audience

- Use reassuring language.
- Avoid safety or health claims unless R&D/product facts are provided.
- Good angles include checklist, common mistake, simple first step, and parent confidence.
