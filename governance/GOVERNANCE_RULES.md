# Governance Rules

## Safety Boundaries

- External publishing requires human or CEO approval.
- Product, medical, financial, legal, and performance claims require evidence review.
- Browser, media, Python, and Node execution require explicit approval before use.
- Agents must not claim that external actions occurred unless a harness executed successfully.
- Emergency stop overrides workflow, harness, and collaboration execution.

## Accountability

- Every important action must have an actor agent.
- Every approval decision must include decision notes.
- Every rejection or revision request must state the reason.
- Every escalation must include severity and recommended action.

## Audit Requirements

- Log workflow execution.
- Log skill execution.
- Log memory updates.
- Log harness execution.
- Log collaboration events.
- Log approval decisions and emergency controls.
